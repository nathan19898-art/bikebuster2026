BIKE BUSTERS 2026 RALLY TRACKER — PWA v4

UPLOAD TO GITHUB PAGES
1. Open the bikebuster2026 repository.
2. Upload everything INSIDE this BikeBusters_2026_PWA folder.
3. Keep index.html, manifest.webmanifest and sw.js at the repository root.
4. Keep all image files inside the icons folder.
5. Commit the changes and wait for GitHub Pages to deploy.
6. Open the live site once in the browser, then close and reopen the installed app.

WHAT CHANGED IN v4
- Replaced the generated logo sheet with separate PWA assets.
- Clean Bike Busters header logo with correct spelling.
- Separate 192 px, 512 px, maskable, Apple touch and favicon images.
- Updated service-worker cache to bikebusters-2026-v4.
- Preserved the v3 tracker functions and locally stored ride records.

If the phone continues to show the previous icon, remove the installed PWA and install it again after GitHub Pages has deployed v4.
